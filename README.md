I build systems that know what they are.

Not a library. Not a framework. A **formal language** — with its own identity algebra,
its own phase model, its own halt conditions. Every value carries a SHA256 signature.
Every operation is reversible until it isn't. Every halt is loud, explicit, and signed.

```
Z4 × Z4  —  16 states. 13 valid. 3 forbidden.

BLID = SHA256( component₁ | component₂ | ... )[:24]

No floating point.
No negative integers.
No silent failures.

If the math doesn't close, it doesn't run.
```

This is **booLang** — ten years of formal research that became a living system.
